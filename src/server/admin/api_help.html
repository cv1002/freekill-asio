GET /api

Display this help page.

GET /api/lsroom GET /api/lsroom?id=<roomId>

List all rooms, or show detail of a specific room (0 = lobby).

Parameters

ParamTypeDescription
idintegerOptional. Room ID. Omit to list all rooms, 0 for lobby.

Response (list all rooms)

{
  "success": true,
  "data": [
    {
      "id": 10,
      "name": "Room A",
      "mode": "aaa",
      "started": false,
      "password": null,
      "playerCount": 3
    }
  ]
}

Response (room detail, id > 0)

{
  "success": true,
  "data": {
    "room": { "id": 10, "name": "Room A", ... },
    "players": [
      { "screenName": "Alice", "id": 1, "connId": 100, "state": "Online" }
    ]
  }
}

Response (lobby, id = 0)

{
  "success": true,
  "data": { "players": [...] }
}

Error

{
  "success": false,
  "error": "No such room."
}
