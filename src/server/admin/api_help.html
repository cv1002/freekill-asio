FreeKill 管理 API

鉴权：所有接口需 Authorization: Bearer <token>， 对应配置 adminHttp.token。写操作 body 为 JSON。

只读

GET /api — 本帮助页
GET /api/players — 在线玩家（Shell: lsplayer）
GET /api/rooms — 房间列表（Shell: lsroom）
GET /api/rooms/{id} — 房间详情，id=0 为大厅
GET /api/server/stat — 状态（Shell: stat）

干预

POST /api/players/kick — {"name":"..."}
POST /api/broadcast — {"message":"..."}
POST /api/rooms/{id}/broadcast — {"message":"..."}
POST /api/rooms/{id}/kill — 踢光并废弃房间
POST /api/lobby/check — 清理大厅死连接

账号

POST /api/accounts/ban — {"names":["a"]}
POST /api/accounts/unban — 连带 unban UUID
POST /api/accounts/ban-ip / unban-ip
POST /api/accounts/ban-uuid / unban-uuid
POST /api/accounts/temp-ban — {"name":"a","duration":"7d"}（m/h/d/mo）
POST /api/accounts/temp-mute / unmute
POST /api/accounts/whitelist — {"action":"add"|"rm","names":[...]}
POST /api/accounts/reset-password — 重置为 1234

配置

POST /api/server/reload-config

错误格式

{
  "success": false,
  "error": { "code": "NOT_FOUND", "message": "..." }
}
