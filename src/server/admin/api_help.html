FreeKill 管理 API

鉴权：所有接口需带 Authorization: Bearer <token>， token 与 freekill.server.config.json 中 adminHttp.token 一致。
GET /api

本帮助页。对应 Shell：help

GET /api/players

列出在线玩家。对应 Shell：lsplayer

{
  "success": true,
  "data": {
    "players": [
      { "id": 1, "connId": 3, "screenName": "alice", "state": "Online", "avatar": "..." }
    ]
  }
}
GET /api/rooms

列出全部房间。对应 Shell：lsroom

GET /api/rooms/{id}

房间详情（id=0 为大厅）。对应 Shell：lsroom <id>

GET /api/packages

列出扩展包。对应 Shell：pkgs

GET /api/server/stat

服务器状态。对应 Shell：stat / gc

错误格式

{
  "success": false,
  "error": { "code": "NOT_FOUND", "message": "No such room." }
}
